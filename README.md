# Multi-threaded Compression System

## Description
A client-server application using TCP sockets and multi-threading.
The server compresses files using GZip and sends them back to the client.

## Features
- Multi-threaded server
- File compression using GZip
- TCP socket programming
- Windows Forms client UI

## Technologies
- C#
- .NET Framework 4.7.2
- TCP/IP
- GZipStream

## How to Run
1. Start the server
2. Open the client
3. Choose a file
4. Send file
5. Receive compressed file
